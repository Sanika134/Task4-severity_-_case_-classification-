### OBJECTIVE
Classify adverse drug reactions based on seriousness and expectedness using pharmacovigilance guidelines. Evaluate clinical impact.

### CASE ANALYSIS AS PER SCREENSHOT

#### CASE 01: Amoxicillin - Skin rash, itching
- Drug: Amoxicillin 500mg
- Reaction: Skin rash, itching
- Seriousness: NON-SERIOUS (Moderate)
- Reason: No hospitalization, no disability, recovered after dechallenge
- Expectedness: EXPECTED - Well documented in drug label as Type B hypersensitivity
- Severity (Hartwig): Level 3 - Moderate
- Action: Drug withdrawn, Antihistamine

#### CASE 02: Ibuprofen - Gastrointestinal bleeding requiring hospitalization
- Drug: Ibuprofen (NSAID)
- Reaction: GI Bleeding requiring hospitalization
- Seriousness: SERIOUS
- Reason: Hospitalization = Serious criteria as per ICH E2A (life threatening)
- Expectedness: EXPECTED - Known ADR of NSAIDs, listed in label
- Severity: Level 5 - Severe
- Outcome: Serious, but expected
- Reporting: Expedited reporting required due to seriousness

#### CASE 03: Metformin - Lactic acidosis
- Drug: Metformin
- Reaction: Lactic acidosis
- Seriousness: SERIOUS / LIFE-THREATENING
- Reason: Life threatening, requires ICU, can lead to death if untreated
- Expectedness: EXPECTED but RARE - Boxed warning, listed as rare but serious ADR
- Severity: Level 6 - Severe / Life threatening
- Risk Factors: Renal impairment, overdose, alcohol

### PHARMACOVIGILANCE GUIDELINES USED
- Seriousness as per ICH E2A: Death, Life-threatening, Hospitalization, Disability, Congenital anomaly, Medically important
- Expectedness as per RSI / Company Core Data Sheet
- Severity as per Hartwig & Siegel Scale (Level 1-7)
- Type: All are Type A (Dose related) except Case 01 Type B

### CONCLUSION
- Case 02 & 03 require expedited reporting within 15 days (Serious)
- Case 01 is non-serious, routine reporting
- All 3 are expected ADRs per label, but severity differs
